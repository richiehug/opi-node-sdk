# 🎉 OPI Node.js SDK is out!

OPI Node.js SDK 1.0.0 brings OPI payment integration to Node.js POS, ECR, and desktop applications. Connect to a separate network terminal while the SDK handles TCP communication, XML messages, terminal callbacks, and transaction results.

## Highlights in 1.0.0

- TypeScript API with Promise-based commands and events for terminal messages and status updates.
- Native two-channel OPI TCP communication with an explicit terminal address.
- Payments, refunds, reversals, and terminal operations.
- Typed transaction results, receipts, and DCC information.
- Separate-channel abort and explicit reprint/repeat-last-message commands.
- Bounded abort responses and prompt handling of detected cashier network loss, preserving uncertain financial outcomes.
- Manual receipt reprint and repeat-last-message operations.
- Receipts are delivered to the application by default, with terminal printing available when configured.
- Your application owns the payment screen and transaction experience. The SDK contains no overlay or branding components.
